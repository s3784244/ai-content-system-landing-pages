## Who This Is For

If you use Claude Code for projects that take more than 20-30 minutes — building features, writing content batches, doing research — you've probably hit the context wall. Claude starts repeating itself, forgetting decisions, or asking questions it already answered.

This cheatsheet fixes that with one command used at the right moment.

## Why /compact Changes Everything

The default behavior when your context fills up is that Claude starts dropping your earliest messages. That means lost decisions, forgotten file paths, and wasted time re-explaining context. `/compact` compresses instead of deletes — keeping the thread alive so your session runs 2-3x longer with no quality drop.
