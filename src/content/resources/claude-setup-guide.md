## What's Inside

This guide walks you through setting up Claude from scratch and using it as a practical AI assistant.

You’ll learn how to:

* **Create your Claude account**
* **Understand the basic Claude interface**
* **Set up Projects for different areas of work**
* **Add useful instructions so Claude gives better answers**
* **Upload documents and ask Claude to summarise or analyse them**
* **Use better prompts for writing, planning, research, and productivity**

By the end of this guide, you’ll have Claude set up in a way that makes it easier to use for real tasks.

## Who This Is For

This guide is for:

* **Beginners** who have heard of Claude but don’t know where to start
* **Professionals** who want to use AI to save time at work
* **Students** who want help with notes, research, and study planning
* **Creators and business owners** who need help with writing, ideas, and organisation
* **Anyone already using ChatGPT** who wants to try Claude as another AI assistant

## Step 1: Create Your Claude Account

Start by creating a Claude account.

Once you’re logged in, take a few minutes to explore the layout. You’ll usually see:

* A chat box where you type your prompt
* A place to upload files
* Your chat history
* A Projects section
* Account and settings options

You can start using Claude straight away by typing a question or task into the chat box.

For example:

“Summarise this article for me in simple language.”

Or:

“Help me write a professional email to my manager.”

## Step 2: Understand What Claude Is Good For

Claude is useful for tasks that involve thinking, writing, summarising, organising, and analysing information.

You can use Claude to:

* Rewrite emails and messages
* Summarise long documents
* Brainstorm ideas
* Plan your week
* Prepare for meetings
* Review notes
* Analyse PDFs
* Create checklists
* Explain complex topics simply
* Turn messy thoughts into structured writing

The best way to use Claude is to give it enough context about what you want, who it is for, and how you want the answer formatted.

## Step 3: Create Your First Claude Project

Projects help you organise your work.

Instead of having every conversation in one place, you can create separate projects for different areas of your life or work.

For example, you could create projects like:

* Work Assistant
* Study Notes
* Business Ideas
* Resume and Job Applications
* Research Assistant
* Content Ideas
* Personal Planning

Each project can have its own instructions, files, and conversations.

This makes Claude more useful because it can understand the purpose of that project and respond in a more relevant way.

## Step 4: Add Project Instructions

Project instructions tell Claude how you want it to behave inside that project.

For example, if you create a project called “Work Assistant”, you could add instructions like this:

“You are my work assistant. Help me write clearly, summarise information, prepare for meetings, organise my thoughts, and turn rough notes into professional outputs. Keep responses simple, practical, and easy to action. Use a professional but natural tone.”

You can also add preferences such as:

* Use simple language
* Keep answers concise
* Give step-by-step instructions
* Use bullet points when helpful
* Make writing sound professional but not robotic
* Ask questions only when absolutely necessary

Good instructions help Claude give answers that match your style and needs.

## Step 5: Upload Useful Documents

Claude can work with documents, which makes it helpful for reading, summarising, and analysing information.

You can upload things like:

* PDFs
* Meeting notes
* Reports
* Research papers
* Draft documents
* Transcripts
* Study notes
* Business plans
* Job descriptions

Once you upload a document, you can ask Claude to help you understand it.

Example prompts:

“Summarise this document in simple language.”

“Give me the key action items from this document.”

“Turn this document into a checklist.”

“Find the most important points I need to know.”

“Rewrite this document so it is clearer and more professional.”

This is especially useful when you have long documents and want to quickly understand the main points.

## Step 6: Use Better Prompts

The quality of Claude’s answer depends on the quality of your prompt.

A vague prompt gives a vague answer.

Instead of writing:

“Help me with this.”

Write:

“Rewrite this message so it sounds professional, clear, and friendly. Keep it short and make it suitable to send to my manager.”

A strong prompt usually includes:

1. What you want Claude to do
2. Who the output is for
3. The tone you want
4. The format you want
5. Any important context

Use this simple prompt structure:

“I want you to help me with [task]. The audience is [audience]. The tone should be [tone]. Please format it as [format]. Here is the context: [insert context].”

## Step 7: Try These Starter Prompts

Here are some prompts you can copy and use inside Claude.

### For Emails

“Rewrite this email so it sounds professional, clear, and friendly. Keep it concise and make sure the message is easy to understand: [paste email].”

### For Research

“Research this topic based on the information I provide. Summarise the key points, explain why it matters, and give me 3 practical takeaways: [insert topic or notes].”

### For Meeting Prep

“Help me prepare for a meeting about [topic]. Give me key talking points, possible questions I should ask, and a short summary I can use to explain my thoughts clearly.”

### For Document Summaries

“Summarise this document in simple language. Give me the main points, key action items, and anything important I should pay attention to.”

### For Planning

“Help me create a simple plan for [goal]. Break it down into clear steps, prioritise what I should do first, and keep it realistic.”

### For Learning

“Explain [topic] to me in a clear and simple way. Assume I understand the basics but want to become more confident talking about it.”

## Step 8: Start With Everyday Tasks

The easiest way to get value from Claude is to use it on small tasks first.

Start with things you already do every day, such as:

* Writing messages
* Summarising notes
* Planning your day
* Preparing for meetings
* Understanding long documents
* Brainstorming ideas
* Creating checklists
* Organising messy thoughts

You don’t need to use Claude perfectly. The goal is to build the habit of using it as a thinking and productivity assistant.

## Common Mistakes to Avoid

When setting up Claude, avoid these common mistakes:

* Starting a new chat for everything instead of using Projects
* Giving very short prompts with no context
* Expecting perfect answers without editing
* Not telling Claude your preferred tone or format
* Uploading documents without asking a specific question
* Using Claude only for writing instead of planning, thinking, and organising too

Claude works best when you treat it like an assistant that needs clear instructions.

## Final Step

Once your Claude account is set up, create one Project and start using it for real tasks.

A good first project could be:

“Personal Productivity Assistant”

Add simple instructions, upload any useful documents, and test a few prompts.

Start small. Use Claude to rewrite one message, summarise one document, or plan one task.

Once you’re comfortable, you can create more projects for different areas of your life or work.

The goal is not to use Claude for everything. The goal is to use it where it saves time, improves clarity, and helps you think better.
